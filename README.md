# Chirpy

A small Twitter-like REST API written in Go. Users can sign up, log in, post short messages ("chirps"), and read or delete them.

This project was built while enrolled in the [Boot.dev](https://www.boot.dev) backend course (_Learn HTTP Servers in Go_). Here is my certificate:

[Boot.dev Certificate](https://www.boot.dev/certificates/9f7c7654-2f7b-4c51-8f11-f1b869bbe4ad)

## Features

- User registration and login, with passwords hashed using Argon2id
- JWT access tokens plus revocable refresh tokens (60-day expiry)
- Create, list, fetch and delete chirps (max 140 characters)
- Profanity filter that replaces banned words with `****`
- Filter chirps by author and sort by creation date
- "Chirpy Red" premium upgrade through a Polka webhook, protected by an API key
- Static file server with a hit counter and an admin metrics page
- Postgres storage with type-safe queries generated by sqlc

## Tech stack

- [Go](https://go.dev) with the standard library `net/http` router
- PostgreSQL via [`lib/pq`](https://github.com/lib/pq)
- [sqlc](https://sqlc.dev) for generating Go code from SQL
- [goose](https://github.com/pressly/goose) for migrations
- [`golang-jwt/jwt`](https://github.com/golang-jwt/jwt), [`alexedwards/argon2id`](https://github.com/alexedwards/argon2id), [`google/uuid`](https://github.com/google/uuid), [`joho/godotenv`](https://github.com/joho/godotenv)

## Getting started

### Prerequisites

- Go
- PostgreSQL
- [goose](https://github.com/pressly/goose) and [sqlc](https://sqlc.dev) (only needed to run migrations or regenerate code)

### Configuration

Create a `.env` file in the project root (it is git-ignored):

```env
DB_URL="postgres://user:password@localhost:5432/chirpy?sslmode=disable"
PLATFORM="dev"
JWT_SECRET="a-long-random-string"
POLKA_KEY="your-polka-api-key"
```

| Variable     | Description                                                       |
| ------------ | ----------------------------------------------------------------- |
| `DB_URL`     | Postgres connection string (required)                             |
| `PLATFORM`   | Set to `dev` to enable `POST /admin/reset`                        |
| `JWT_SECRET` | Secret used to sign and verify JWTs                               |
| `POLKA_KEY`  | API key the Polka webhook must send in the `Authorization` header |

### Run

```sh
# Create the database, then apply migrations
goose -dir sql/schema postgres "$DB_URL" up

# Start the server on :8080
go run .
```

### Test

```sh
go test ./...
```

### Regenerate database code

After editing anything in `sql/schema` or `sql/queries`:

```sh
sqlc generate
```

## API

Authenticated endpoints expect `Authorization: Bearer <JWT>`.

### Users and auth

| Method | Path           | Auth          | Description                                              |
| ------ | -------------- | ------------- | -------------------------------------------------------- |
| POST   | `/api/users`   | none          | Create a user (`email`, `password`)                      |
| PUT    | `/api/users`   | JWT           | Update the current user's email and password             |
| POST   | `/api/login`   | none          | Log in. Returns a JWT (up to 1 hour) and a refresh token |
| POST   | `/api/refresh` | refresh token | Exchange a valid refresh token for a new JWT             |
| POST   | `/api/revoke`  | refresh token | Revoke a refresh token                                   |

### Chirps

| Method | Path               | Auth | Description                                                |
| ------ | ------------------ | ---- | ---------------------------------------------------------- |
| POST   | `/api/chirps`      | JWT  | Create a chirp (`body`, max 140 chars)                     |
| GET    | `/api/chirps`      | none | List chirps. Optional `?author_id=<uuid>` and `?sort=desc` |
| GET    | `/api/chirps/{id}` | none | Get a single chirp                                         |
| DELETE | `/api/chirps/{id}` | JWT  | Delete a chirp (only its author can)                       |

### Webhooks

| Method | Path                  | Auth                                | Description                                           |
| ------ | --------------------- | ----------------------------------- | ----------------------------------------------------- |
| POST   | `/api/polka/webhooks` | `Authorization: ApiKey <POLKA_KEY>` | Handles the `user.upgraded` event to grant Chirpy Red |

### Misc

| Method | Path             | Description                                                        |
| ------ | ---------------- | ------------------------------------------------------------------ |
| GET    | `/api/healthz`   | Health check, returns `OK`                                         |
| GET    | `/app/`          | Static site from `static/`, counted for metrics                    |
| GET    | `/admin/metrics` | HTML page showing how many times `/app/` has been visited          |
| POST   | `/admin/reset`   | Deletes all users (and their chirps). Only works if `PLATFORM=dev` |

### Example

```sh
# Create a user
curl -X POST localhost:8080/api/users \
  -H "Content-Type: application/json" \
  -d '{"email":"me@example.com","password":"hunter2"}'

# Log in
curl -X POST localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"email":"me@example.com","password":"hunter2"}'

# Post a chirp
curl -X POST localhost:8080/api/chirps \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"body":"Hello, Chirpy!"}'
```
